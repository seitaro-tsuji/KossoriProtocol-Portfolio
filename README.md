## 制作形態
5人チームで、企画・設計・素材選定・実装までを2日間で行い、ゲームを完成させました。

### 担当箇所
- インゲームのシステム部分の実装
- 他メンバーが制作したプレイヤー・マップ・敵キャラクター・アイテムなどのシーンへの配置・統合
- 複数のオブジェクト間で連携が必要な処理の実装
- シーン遷移処理およびフェードイン・アウト演出の実装
- BGM・SEを管理するクラスの実装

## ゲーム概要
2D見下ろし型のステルスゲームです。

プレイヤーは、マップ内にランダムに配置された敵の視界を避けながらゴールを目指します。敵に接触したり、一定の条件で視界に捉えられたりするとゲームオーバーになります。

マップ内には移動速度を上げるアイテムや、すべての敵を一時的に停止させるアイテムが配置されており、これらを活用してゴールを目指します。

クリアタイムが記録されるため、より短い時間でのクリアを目指して繰り返し挑戦できるゲームです。

## 操作方法
### キーボード・マウス
- **WASD / 方向キー**：移動
- **Shiftキー**：ダッシュ
- **Enter**：ゲームスタート・リスタート
- **Escape**：タイトルに戻る

「ゲームスタート」や「タイトルに戻る」などは、ゲーム内に配置されたボタンをクリックすることでも可能です。

### ゲームパッド(インゲームのみ)
※Xboxのボタン表記
- **左スティック / 十字キー**：移動
- **Bボタン**：ダッシュ
- **Xボタン**：リスタート
- **メニューボタン**：タイトルに戻る

※ゲームパッドの操作は2日間の開発期間終了後に個人で追加した機能です。現在はインゲーム部分のみ対応しています。

## 工夫した点
### 開発方針
制作期間が2日間と限られていたため、素材選定の時間を削るためにUnityに用意されている基本の図形を主に使用しました。

また、「ゲームとして最低限成立する作品」をまず完成させ、残った時間で要素を追加していくという実装順を意識しました。

さらに、タイム短縮を目指して短いスパンで繰り返しプレイするゲームになるため、ゲーム終了から再スタートまでの時間をなるべく短くし、プレイする人がリプレイ時にストレスを感じないようにしました。

### 最低限の完成ライン
- タイトル→インゲーム→リザルトのゲームループの完成
- インゲーム内からリザルトやタイトルを経由せずにすぐにリスタートできる機能
- マップ内への敵キャラクターの配置と、敵キャラクターの移動・視点変更
- 敵に見つかったときのゲーム失敗の処理

### 追加で実装できた機能
- スピードアップアイテム・スタンアイテムの実装
- マップ・敵・アイテムのランダム生成
- サウンドの実装やアイテム取得時の文字演出
- 連続クリア時のリザルト表記
- ダッシュ中に敵に気づかれやすくなる仕様の追加
